# BrandPilot

An AI social media marketing platform: brand intelligence, strategy, on-brand creatives,
copy, campaigns, a content calendar, publishing with human approval, analytics and billing.

The app lives in [`web/`](web/). Start with [`web/README.md`](web/README.md) for setup and
[`web/docs/ARCHITECTURE.md`](web/docs/ARCHITECTURE.md) for the architecture and roadmap.

```bash
cd web
npm install
cp .env.example .env.local   # add ANTHROPIC_API_KEY, or set AI_PROVIDER=mock to try it without keys
npm run dev                  # http://localhost:3000
```
